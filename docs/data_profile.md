# Профиль исходных данных

Результаты разбора `docs/internal_files/contractors_audit.snapshot.json`.
Документ описывает, **что лежит в данных** — измерения, распределения, ловушки формата.
Архитектурные решения, которые из этого следуют, живут в `architecture.md`.

Снапшот: 100 контрагентов, дамп MongoDB (Extended JSON), даты отчётов —
конец июля и август 2026. Замеры сделаны на загруженной БД.

### Подбор порогов детектора

Абсолютный порог по сумме активных производств среди 66 зелёных компаний:

Абсолютное значение не работает: 10 млн ₽ для микропредприятия — катастрофа,
для МАКСМАРКЕТА с выручкой 116 млрд ₽ — погрешность. Относительный порог
(доля от выручки) с двумя подпорками даёт 4 срабатывания из 66:

| Компания | Причина |

## 6. Чего в данных нет

* **Конкретных судебных дел.** Только агрегаты: `arbitrationCases[]` =
  `{year, plaintiffCount, plaintiffAmount, defendantCount, defendantAmount}`
  за 2023–2026 и `arbitrationByStatus` (закрытые / обжалованные / открытые,
  отдельно по сторонам). Ни номеров дел, ни сторон, ни предметов спора.
* **Численности персонала** — `staff` пуст у всех 100.
* **Связного графа контрагентов.** 249 рёбер `relatedCompanies` ведут на 247
  различных ИНН, и лишь **2** указывают внутрь снапшота.

**Стороны в арбитраже не сходятся с общим счётчиком.** У ЛЕ МОНЛИД
`commonCount` = 1525, а истец (1049) плюс ответчик (439) дают 1488 —
37 дел без классификации стороны.

## 7. География

Адрес — свободная строка, но формат жёсткий: `индекс, РЕГИОН, район, город, улица`.
Регион — всегда второй элемент, разбор проверен на всех 75 адресах,
27 различных значений, ни одного исключения.

| Регион | Контрагентов |
|---|---:|
| Москва | 26 |
| Московская область | 6 |
| Санкт-Петербург | 5 |
| Краснодарский край | 4 |
| Республика Татарстан | 3 |
| остальные 22 региона | по 1–2 |

Адрес отсутствует у 25 контрагентов.

Подстрочное сравнение регионов даёт ложные срабатывания:
запрос «Марс» попадает в «Са**марс**кую область».

## 8. Ловушки формата

| Ловушка | Где встречается |
|---|---|
| `{"$date": "..."}` | все даты |
| `{"$numberLong": "..."}` | 15 значений в `proceeds`, 10 в `totalAssets`, ещё около 20 в других полях |
| `amount` строкой `"517235.54"` | `executionProceedings[]` |
| коэффициенты строками `"0.04"` | `coefficient` |
| **кириллическая «а»** в коде `аrbitrationDefendant` против латинского `arbitrationDefendant` | `reputationalRisks`: положительные и отрицательные варианты одного кода записаны разными алфавитами |
| до 121 кода ОКВЭД на компанию, в среднем 22 | `kindsOfActivityInfo` |

Числовые поля с `$numberLong` меняют статистику: без разворачивания
`proceeds` выглядит заполненным на 79 %, после — на 87 %.
