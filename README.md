# Проверка контрагентов с ИИ

ИИ-агент, который разбирает банковский отчёт по контрагенту, называет риски
человеческим языком и отвечает на вопросы по нему в диалоге.

Клиент вставляет ИНН — получает вердикт, риски, сильные стороны и графики.
Дальше может спросить своими словами или углубиться в тему по кнопке.

**Принцип:** все факты, числа и вердикты считает код. Модель только формулирует
текст — она не имеет доступа к базе и не делает арифметику. Агент не может
придумать цифру, потому что не умеет получать их иначе как от кода.

---

## Что умеет

* Разбор одного контрагента: вердикт, риски, сильные стороны, график выручки
* Сравнение 2–10 контрагентов таблицей с рейтингом
* Диалог по отчёту с конкретными числами в ответе
* Углублённые разборы: финансы, суды, владельцы, деятельность
* Подбор альтернативы, если контрагент не подошёл
* Список документов, которые стоит запросить у контрагента
* Работа без модели: если поставщик недоступен, отдаётся отчёт из данных

## Запуск

```bash
docker compose -f devops/docker-compose.yml up -d

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m scripts.load_data

python app.py serve
```

Фронтенд отдельным терминалом:

```bash
cd src/ui && npm install && npm run dev
```

Приложение — `http://localhost:5173`, API — `http://localhost:8000`.

Настройки в `config/internal_config.yaml`, секреты в `.env` по образцу
`.env.example`: доступ к базе, `LLM_API_KEY`, `AUTH_LOGIN`, `AUTH_PASSWORD`.

## Структура

```
src/core/     чистые функции: факт-пакет, агрегаты, вердикт, подсказки
src/db/       модели и репозитории
src/mcp/      24 инструмента поверх ядра
src/agent/    роутер, префетч, контекст, лимитер, вызов модели, починка
src/webapp/   FastAPI: маршруты, схемы, зависимости
src/ui/       React-приложение
scripts/      загрузчик снапшота в базу
```
